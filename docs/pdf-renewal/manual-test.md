# PDF リニューアル 手動テスト手順

新方式（jspdf-autotable + 日本語フォント埋め込み）の動作確認用チェックリスト。
画面のPDFボタン押下から始めて、以下のケースを順に試す。

## テストの入口

- 見積書: `/dashboard/orders/<id>/estimate` → 「PDFで開く」
- 請求書: `/dashboard/orders/<id>/invoice` → 「PDFで開く」

ファイルが `見積書_YYYYMMDD_顧客名_管理No.pdf` / `請求書_…` の形でダウンロードされる。

## 必須チェックケース

それぞれ「見積書」と「請求書」両方で試す。

### 1. 1ページで収まる注文

- [ ] 明細 1〜3 件
- [ ] タイトル「見積書」or「請求書」が中央に大きく表示される
- [ ] 文書情報（管理No / 発行日 / 受付日）が右上に表示
- [ ] 顧客名（左）と店舗情報（右）が表示される
- [ ] 車両情報の枠が表示される
- [ ] 明細テーブルにヘッダー（品名 / 数量 / 工賃 / 部品代 / 小計）と本体が表示
- [ ] 合計欄（課税対象額 / 消費税 / 合計）が右寄せで表示
- [ ] 続きページが発生しない（1ページ目のみ）

### 2. 複数ページにまたがる注文

- [ ] 明細を 30〜50 件にして 2〜3 ページに分かれる
- [ ] 2ページ目以降の上部に「見積書（つづき）」or「請求書（つづき）」帯
- [ ] 帯の中央に「管理No 顧客名 様」、右に「2 / 3」など
- [ ] 帯の下端に薄い水平線
- [ ] 2ページ目以降のテーブルヘッダー（品名 / 数量 / …）が **繰り返し** 表示
- [ ] カテゴリ見出し行（【整備】【車検（課税）】【車検（非課税）】）が崩れない
- [ ] 本文と帯（marginTop = 25mm）が重ならない

### 3. 値引きあり / なし

- [ ] 値引き 0 円: 合計欄に「値引き」行が出ない
- [ ] 値引きあり: `− ¥xxx` で値引き行が表示、上に区切り線

### 4. 預かり金あり / なし

- [ ] 預かり金 0 円: 合計の下に「預かり金」「差引請求額」が出ない
- [ ] 預かり金あり: `− ¥xxx` の預かり金 → 「差引請求額」が二重線強調で表示

### 5. 見積書 / 請求書 両方

- [ ] 見積書: 振込先 / 振込期限ブロックが **出ない**
- [ ] 請求書: 振込先 / 振込期限ブロックが描画される（条件は下記）

### 6. ロゴあり / なし

- [ ] ロゴあり: 左上に店舗ロゴが表示（最大 30mm × 18mm でアスペクト比保持）
- [ ] ロゴあり: 全ページ中央に薄い透かしロゴ（不透明度 〜0.08）
- [ ] ロゴなし: 左上空白、透かしなし、エラーなく PDF 生成完了

### 7. 印鑑あり / なし

- [ ] 印鑑あり: 店舗名の右側に重ねて表示（最大 22mm × 22mm）
- [ ] 印鑑なし: 店舗名のみ表示、エラーなし

### 8. 備考あり / なし

- [ ] 備考あり: 「備考」見出しと本文（改行保持）
- [ ] 備考の長文: 自動折り返しが効く
- [ ] 備考なし: ブロックごと出ない

### 9. 振込先未設定の請求書（フォールバック挙動）

- [ ] 振込先 4 項目（銀行・支店・口座・名義）すべて空: 振込先ブロックが **出ない**
- [ ] `payment_due_date` が null: 振込期限ブロックも出ない
- [ ] それでも合計欄・備考は正しく表示

### 10. 明細 0 件

- [ ] 「明細がありません。」のメッセージが表示
- [ ] 合計欄も非表示 or ¥0 で破綻しない

## 車検（非課税）に関する個別検証（C 案）

- [ ] `labor_cost` も `parts_cost` も未設定の明細: 「工賃」「部品代」セルが結合（colSpan: 2）され `unit_price` が 1 セルに表示される
- [ ] `labor_cost` または `parts_cost` のいずれかが入っている明細: 通常の 5 列表示
- [ ] 同じカテゴリ内に「結合行」と「5 列行」が混在しても破綻しない
- [ ] 2ページにまたがる場合でも colSpan 行が正しく描画される

## 既知の挙動・確認外

- 旧 `lib/pdf/generate-pdf.ts` は `@deprecated` のまま残置。Step 7 で削除する。
- HTML 帳票（`/dashboard/orders/<id>/estimate` の本文）は今回触らない。
- `pdf-v2-test` 検証ページは Step 6 で削除済み。
